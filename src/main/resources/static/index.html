Centre d’aide

Trois guides pour utiliser le site pas à pas.

Comment faire enregistrer ma moto

  1. Venez dans un bureau MotoSûr avec votre moto, votre pièce d’identité et les papiers de la moto.
  2. Deux agents relèvent ensemble la plaque, le châssis et le moteur sur la moto.
  3. Vous payez les frais d’enregistrement et recevez un reçu.
  4. Gardez le reçu : il porte votre numéro d’enregistrement et votre code secret.

Comment vérifier une moto

  1. Demandez au vendeur la plaque ou le numéro de châssis.
  2. Saisissez-le dans « Vérifier une moto ».
  3. Lisez le résultat : « En règle », « Signalée volée » ou « Non enregistrée ».
  4. Si la moto est signalée volée, ne payez rien et prévenez le commissariat le plus proche.

Comment déclarer une moto volée

  1. Prenez votre reçu (numéro d’enregistrement et code secret).
  2. Ouvrez « Déclarer un vol » et saisissez le numéro du reçu.
  3. Indiquez la date, le lieu et ce qui s’est passé, puis confirmez avec votre code secret. Reçu perdu : allez au bureau.
  4. L’alerte part vers tous les commissariats de Bamako. Si vous retrouvez votre moto, utilisez « Ma moto est retrouvée » sur la même page.
